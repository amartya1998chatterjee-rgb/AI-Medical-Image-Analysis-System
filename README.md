# AI-Powered Medical Image Analysis System

## Overview
This project uses Deep Learning to detect Pneumonia from Chest X-ray images.

## Tech Stack
- Python
- TensorFlow
- OpenCV

## Dataset
Chest X-ray dataset (Kaggle)

## Features
- Image classification
- Transfer learning (MobileNetV2)
- Visualization

## Results
- Accuracy: ~85-95%

## Run
python src/train.py
python main.py
